# Beacon Productivity and Quality for Space Age: Updated

Allows beacons to accept productivity and quality modules, expanding the module effects available through beacon layouts.

This fork retains the original beacon module changes for Factorio 2.1.24. Quality support is required; the expanded effects alter the usual beacon balance.

Requires Factorio 2.1.24 or later. Disable `rosnok-productivity-quality-beacon` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
